
## v1.5.1 更新：AI 改为额度制（算力点）

- **计费单位**：算力点。单价 = 算力点 / 千 token，可按模型单独设置（默认 deepseek-chat 1、deepseek-reasoner 2）。
- **双重额度**：滚动的 **5 小时窗口额度** + **自然月额度**，两者取更紧的一个；**任一用尽立刻停止输出**。
- **超出即停的四道保险**：
  1. 请求前预检，额度不足直接返回 402 + `QUOTA_EXCEEDED`，不发起调用；
  2. 发起时按剩余额度折算 `max_tokens`，从源头限制输出长度；
  3. 流式输出过程中按已生成字符实时估算消耗，一旦达到额度立即下发 `QUOTA_EXCEEDED` 事件并掐断；
  4. 结算消耗不会超过剩余额度。
- **管理员可调**（`/admin/ai`）：窗口时长、默认窗口额度、默认月额度、默认单价、每个模型的单价；对每个用户单独分配窗口/月额度（填 0 = 用全局默认）、给某人加本月额度、清零本月用量。
- **兑换码 / 商城 Token** 自动折算成算力点，加到用户**本月额度**上。
- 数据文件：`data/ai_quota.json`（配置）、`data/ai_usage.json`（各用户 5 小时窗口事件 + 本月累计）。
- 对话页顶部实时显示：⚡ 剩余算力点、⏳ 5 小时窗口用量、📅 本月用量；额度耗尽时输入框锁定并提示。
- 接口：`GET /llm/api/quota` 返回 `{windowQuota, windowUsed, monthQuota, monthUsed, remaining}`。
- 测试：`node tools/test_quota.js`（16 项：默认额度、计费、402 拦截、输出中途中断、配置落盘、恢复默认）。

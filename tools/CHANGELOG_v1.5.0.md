## v1.5.0 更新（2026-10）

### 1. 学习 / 社区分区
- 侧栏导航改为三段：**学习**（题库 / 题单 / 试卷 / 比赛 / 提交状态 / 试运行）、**社区**（讨论区 / 博客 / 排行榜 / 对决）、**我的**（主页 / 消息 / 收藏 / 任务 / 云盘 / 设置）。
- 首页顶部新增「学习」「社区」两个入口卡片，侧栏快捷链接同步分组。

### 2. 试卷（选择题 + 填空题）
- 页面：`/papers` 列表、`/paper/<id>` 作答、`/paper/<id>/result/<sid>` 逐题结果与解析、`/paper/<id>/subs` 成绩榜。
- 管理：`/admin/papers` 新建 / 编辑 / 发布 / 下架 / 删除。
- 题型：单选、多选（多选全对才给分）、填空（多空用 `|` 分隔，同一空多个可接受答案用 `,` 分隔，按空给部分分）。
- 满分奖励：20 金币 + 30 经验。
- 数据文件：`data/papers.json`、`data/paper_subs.json`。

### 3. SPJ（Special Judge 特殊评测）
- 题目新增/编辑页新增 **SPJ 源码** 输入框，留空即标准答案比对。
- 约定：checker 接收三个命令行参数 `输入文件 标准输出文件 选手输出文件`；退出码 0 = 通过，非 0 = 答案错误；**stdout 第一行**会显示给选手（如 `expected 8 got 0`）。
- 每个提交只编译一次 checker；编译失败自动回退标准比对并在评测结果里提示。

### 4. 移除本地大模型，AI 改用 DeepSeek
- 删除 `LLM\` 目录（约 8.7GB）与启动时拉起 Ollama 的逻辑（`setupOllamaGpu`、环境变量注入、进程检测）。
- `/llm/api/chat` 直接转发 DeepSeek `/chat/completions` 流式接口（OpenAI 兼容），前端无需改动。
- 配置：`data/ai.json`（`apiKey` / `baseUrl` / `model`）。

### 5. 论坛洛谷化（约 80%）
- **板块**：学术区 / 灌水区 / 组队区 / 站务区；首页展示各板块主题数、今日发帖、最新主题，侧栏「最新回复」「热门主题」。
- **列表**：最新回复 / 最新发布 / 最热 三种排序，只看精华、我的帖子、标签筛选（求助/讨论/经验/分享/公告）、站内搜索、分页，置顶帖恒在最前。
- **楼层**：`#1 #2 …` 楼层号 + 楼中楼（内联回复表单）、每楼独立点赞。
- **互动**：点赞、收藏、`/my/favorites` 收藏夹、`@用户名` 提醒、回复通知楼主、编辑主题、关联题目。
- **管理**：置顶、加精、锁定（锁定后禁止回复）、移动板块。
- **数据**：`Post` 新增 `board/tags/pinned/essence/locked/lastReplyTime/favoritedBy/editTime`，`Comment` 新增 `parentId/likedBy`（旧数据自动兼容，默认学术区）。
